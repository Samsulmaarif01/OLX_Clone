# OLX Clone

Platform jual beli online berbasis PHP & MySQL — clone dari OLX Indonesia.

## Fitur

- Manajemen pengguna (registrasi, login)
- Kategori iklan
- Pasang iklan dengan gambar
- Pencarian & filter
- Halaman detail iklan

## Database

Struktur database mencakup tabel: `users`, `categories`, `ads`, `ad_images`.

## Cara Menjalankan

1. Letakkan folder ini di `C:\laragon\www\` atau `C:\xampp\htdocs\`
2. Import file SQL ke phpMyAdmin
3. Akses `http://localhost/OLX_Clone`
